 - NodeMCU 1.0 (ESP-12E Module)
 - CPU Freq: 80MHz
 - VTables: Flash
 - C++ Exception: Disabled
 - Stack Protection: Enabled
 - SSL Support: All SSL
 - MMU: 16KB + 48KB IRAM and 2nd Heap
 - Flash Size: 4MB( FS:1MB OTA"~1019KB)
 - Builtin Led: 2
 - lwIP Variant: v2 Lower Memory
 - Erase Flash: Only Sketch
